# Text Sorter

A utility for organizing lists of text.

## Features

- Alphabetical sorting
- Reverse sorting
- Duplicate removal

## How to Use

Enter one item per line and choose an operation.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
